## Compiling

Step-by-step on compiling from source code:

1. Install [HaxeFlixel](https://haxeflixel.com/documentation/getting-started/)
2. Download Repo ZIP
3. Unzip your repo ZIP somewhere and open it in the terminal
4. Run `.\libraries.bat`
5. Run `lime test hl`, `lime test windows`, `macos`, or `linux`
6. Complete :D
